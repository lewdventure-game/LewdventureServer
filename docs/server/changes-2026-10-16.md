## Что изменилось на сервере

### Бой (считает ядро, клиенту повторять не нужно)

- КОМБО_1_МН и КОМБО_2_МН снова раздельные: бонусы `combo_2_multiplier_local/perk/global` (`BonusType` 59–61), константа `combo_2_multiplier_base`, у мобов `combo_2_multiplier`.
- БРОНЯ округляется вниз.
- Вампиризм — от реально снятого ХП, без урона сверх остатка.
- Воскрешение заканчивает ход всей стороны, чей ход идёт; если юнит умер в свой ход — ходит противник.
- Статус урона от погибшего наложившего тикает по его статам.
- Воздух и вода не снимают усиленные ожог и яд.
- `set_bonus` и `bonus_change`: каждая выдача — отдельный стак со своим сроком.
- Константы `max_health_base` и `armor_base` (старые имена читаются с предупреждением).

### Забег

- Бой применяется только после `battle/finish`; сдача во время боя отбрасывает его без наград, этап не засчитывается.
- Награды `perk:<id>:<кол-во>` и `perk_group:<id>:<кол-во>` — только внутри забега.
- За последней строкой `Exp_levels_patterns` повторяется последняя; перки на повышении — из строки достигнутого уровня.
- Срок бонуса — строго по `work_modes`: `permanent` / `if_equipped` уходят на аккаунт, остальные живут в забеге.

### Профиль

- Промоут персонажа вручную, копии копятся; сам применяется только бесплатный первый шаг.
- Во время забега нельзя менять персонажа, саммонов, снаряжение и нельзя прокачиваться.

### Конфиги

- `skin_name` у `Characters` и `Summons`; `art_name` у них необязательная, без неё `ArtName` берётся из `skin_name`.
- `start_perk_groups` — список id групп `1;2;3`.

## Для геймдизайна

- В листе скилла 1 `set_bonus` выдаёт бонус с `permanent` — теперь это навсегда на аккаунт на каждом касте. ГД обещал убрать `permanent` из скиллов.
- Открытые вопросы — [§9 п.19–22](../gdd/11-open-questions.md): снаряды после смерти цели, редкости саммонов для overflow, `rewards` у события `fight`, константа `is_equipment_enabled`.
