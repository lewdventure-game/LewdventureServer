# Инструменты для QA: читы, чистка, логи

Branch: master
Created: 2026-10-05

## Settings

- Testing: yes — unit на редактор профиля, лимиты прокачки, валидатор `Cheats`, построитель запросов аналитики; integration на Mongo для QA-метки и читов
- Logging: новые теги `[Qa]` (метка тестового аккаунта, поиск) и `[Cheat]` (любое изменение профиля читом) — согласованы владельцем 2026-10-05
- Docs: `docs/server/qa-tools.md`, `docs/runbooks/admin-panel.md`, `docs/server/player-state.md`, `docs/runbooks/configuration.md`
- Roadmap: фазы 1–4, каждая отдельным коммитом в master

## Решения владельца

- Читы включены на dev и stage, на prod запрещены валидатором при старте.
- Всё через веб-админку и admin API на ops-порту; игровой QA-API для клиента — позже, по желанию.
- Все читы доступны роли `tester`; удаление аккаунта — только `admin`.
- Клиент не трогаем: клиентской команде только документация.

## Фаза 1. Основа и выдача

- `Cheats:Enabled` (`CheatOptions`), валидатор: `true` в Production — ошибка старта. Включено в Local, Development, Staging.
- QA-метка в `users.qa` (`alias`, `markedBy`, `markedAt`), уникальный sparse-индекс `qa.alias`. Метка снимает назначение A/B; помеченный не попадает в эксперименты. Метка и поиск работают и без читов.
- Поиск игрока по `userId`, псевдониму или `deviceId` (sha256 как при входе).
- Каталог конфигов для выпадающих списков: персонажи, саммоны, снаряжение, бонусы аккаунта, ключи ресурсов, уровни сюжета, максимальные уровни.
- Читы: «выдать всё» пресетами, установить ресурс и флаг, уровень промоута персонажа, уровень, мастерство и скиллы саммона, уровень снаряжения, «максимум всему», сброс прогресса, прерывание забега. Повышение промоута и мастерства выдаёт награды пройденных уровней, как в обычной прокачке. Записи в журнал с действием `cheat`.
- Аналитика админки по умолчанию исключает QA-аккаунты (`user_id NOT IN`), переключатель «Показать тестовые аккаунты».

## Фаза 2. Любой прогресс за секунды

- Шаблоны прогресса: сохранить профиль как шаблон, применить к игроку, скопировать прогресс A → B.
- Сюжет: отметить уровни пройденными.
- Читы забега: этап N, событие следующего этапа, здоровье/опыт/уровень, перк/бонус/статус в забег, фиксированный seed, «лёгкий бой» для QA-аккаунтов без влияния на golden.

## Фаза 3. Логи и баг-репорты

- Трасса запросов игрока вне prod в TTL-коллекции (7 дней): путь, статус, длительность, `correlationId`, тело запроса и ошибки без токенов.
- Страница «Ошибки сервера» с поиском по `correlationId` и `userId`.
- Кнопка «Баг-репорт»: один JSON с профилем, забегом, запросами, событиями, версиями.
- Документация клиенту: показывать `userId` и `X-Correlation-Id`.

## Фаза 4, по желанию

- Принудительная группа A/B для QA-аккаунта.
- Игровой `/api/qa/*` по Bearer при `Cheats:Enabled`.
- Сдвиг серверного времени игрока, когда появятся таймеры.
